# zoomer

Inspire from Mr. Zozin's boomer: https://github.com/tsoding/boomer

# Build
```shell
cmake -S . -B build
cmake --build build -j4
```

# Control
- Scroll wheel: Zoom in/out
- Left mouse button: Drag the view point around while zoomed in
- Right mouse button: Reset the view point
- Middle mouse button: Toggle light bulb effect
